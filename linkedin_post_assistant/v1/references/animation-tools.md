# Ferramentas de animação

## Roteamento

### Remotion — padrão

Use o template em `assets/remotion-template/` para o fluxo automatizado local. Remotion cria
vídeos com React e oferece render de vídeo e still pela CLI. Verifique licença e requisitos
atuais antes de uso empresarial; não o descreva como universalmente gratuito.

- Render: <https://www.remotion.dev/docs/render>
- Requisitos: Node.js 20.19 ou superior para as dependências fixadas neste template.

### Motion Canvas — alternativa técnica

Escolha quando a explicação depender de sequência vetorial complexa, algoritmo passo a passo
ou sincronização detalhada. É uma biblioteca TypeScript com generators e editor de preview.

- Documentação: <https://motioncanvas.io/docs/>

### Jitter — alternativa visual manual

Use quando edição manual trouxer ganho visual claro. Formatos, resolução e marca d'água variam
por plano; confirme as condições atuais antes de prometer o artefato.

- Exportação: <https://help.jitter.video/en/articles/5369843-export-your-work>

### Canva — alternativa acessível manual

Use para ajustes simples quando o usuário preferir editor visual. MP4, GIF, qualidade e opções
de exportação podem depender do plano.

- Exportação: <https://www.canva.com/en_gb/help/download-as-video/>

## Entrega para LinkedIn

Prefira MP4 com fundo opaco. Gere `capa.png` em todas as execuções e GIF somente quando houver
motivo específico. Confirme os formatos atuais na documentação oficial antes de alterar os
parâmetros do template:

- <https://www.linkedin.com/help/linkedin/answer/a564111>
